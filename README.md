# Qiu Skills

## 我的短视频封面导演

把选题、口播稿或已有素材变成一份可以直接用于生图的抖音封面提示词。适合 AI 工具教程、概念科普、成长经验、访谈和探展。

[查看 Skill 完整说明](personal-video-cover/SKILL.md)

### 它会怎么问

1. **选标题**。根据内容给出 2–3 个候选，说明推荐理由。你已经定好的标题会原样使用。
2. **选画面**。每个选项都说明人物站哪儿、做什么动作、用哪个道具表现主题。
3. **补素材**。需要本人出镜时，可提供一张清晰照片。有软件截图、Logo 或希望延续的旧封面，也可以一起发。

每次只问一个问题，已提供的信息直接沿用。想快速拿方案，可以回复「你定」。

### 三种封面方向

| 方向 | 适用选题 | 画面特点 |
| --- | --- | --- |
| 工具系列 | AI 工具教程、知识库、工作流 | 延续系列配色和构图，用工具界面、图标或使用成果讲清主题 |
| 概念海报 | AI 科普、观点、对比 | 把抽象概念变成一个好懂的道具或场景 |
| 真人场景 | 成长经验、访谈、探展 | 用真实场景和人物表情交代内容，给大标题留出清晰位置 |

### 在 Codex 中使用

将整个 `personal-video-cover` 文件夹复制到本机的 `~/.codex/skills/` 目录。识别到 Skill 后，可以这样调用：

```text
$personal-video-cover 我要做一期「用 WorkBuddy 把散落的资料整理成个人知识库」
的抖音封面。希望延续黑底蓝字的系列风格，先给我几个标题让我选。
```

你会收到最终标题及换行、人物动作、主道具、背景配色、参考图用途和完整生图提示词。需要直接出图时，可以在请求里说明，Codex 会在有可用生图工具时按选定方案生成。
